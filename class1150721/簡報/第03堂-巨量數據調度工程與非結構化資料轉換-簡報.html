核心概念 1

為什麼資料處理是 Agent 的核心能力？

企業裡大量工作時間花在「整理資料」：把多份 Excel 報表合併成一份、從上百筆記錄中找出符合條件的資料、將不同格式的資料統一成標準格式。這些工作重複性高、規則性強，是 AI Agent 最能發揮價值的場景。

典型企業痛點：每個月月底，業務助理要花一整天，手動把 20 個業務員各自回傳的 Excel 報價單，複製貼上到一份匯總表裡，再計算每個業務的總業績。用 Agent 處理，整個流程可以在幾分鐘內完成。
核心概念 2

結構化資料 vs. 非結構化資料

結構化資料非結構化資料
定義有固定格式，可直接用程式讀取沒有固定格式，需要解析才能使用
範例Excel 表格、CSV 檔、資料庫PDF 報告、電子郵件、掃描圖片
處理難度相對容易需借助 AI 或 OCR 技術
典型工作篩選、排序、計算資訊提取、摘要、分類
核心概念 2

從非結構化轉為結構化的典型流程

原始資料PDF 合約、郵件內文、掃描文件
→
AI / OCR 解析提取關鍵欄位並清理驗證
→
結構化資料表可存入 Excel 或資料庫

有了結構化資料表，才能進行後續分析與報表生成，產出最終報告。

核心概念 3

Excel / CSV 自動化處理工具

工具適用情境特點
openpyxl讀寫 .xlsx 格式的 Excel可保留原有格式、樣式

核心概念 3

試算表操作的基本動作

動作說明
讀取（Read）從檔案載入資料到程式
篩選（Filter）只取出符合條件的列
排序（Sort）依照某欄位大小排列順序
計算（Calculate）加總、平均、計數等
寫入（Write）把處理結果存回檔案
核心概念 4

跨活頁簿資料整合（批次處理）

批次處理（Batch Processing）是指一次性處理大量同類型任務，而不是一筆一筆手動處理。

資料夾結構：
  /業務報表/
    ├── 北區業務_王大明.xlsx
    ├── 中區業務_李小華.xlsx
    ├── 南區業務_張美玲.xlsx
    └── ... (共 20 個檔案)

目標

自動讀取所有檔案 → 彙整到一份「匯總表.xlsx」→ 計算各業務業績合計

核心概念 4

批次處理的核心邏輯

1. 找到檔案列出資料夾內所有需要處理的 .xlsx 檔案
2. 逐一處理迴圈讀取每份檔案，提取需要的欄位
3. 整理計算對總彙整清單進行排序、計算、格式化
4. 輸出結果將整理後的資料寫入新的 Excel 檔案
核心概念 5

AI 在資料處理中的角色

傳統資料處理需要明確規則，但現實世界的資料往往格式不統一，這時 AI 就能發揮作用：

角色說明範例
格式識別理解不同格式的資料代表什麼「NT$12,000」「12000元」都代表 12000 元
缺失值補充根據上下文推斷缺失的資訊從「台北辦公室」推斷地區為「北區」
異常偵測找出資料中不合理的值業績填寫為負數 → 可能是錯誤

實作三

AI Agent 驅動的資料清理

我要建立一個資料清理 Agent：
1. 讀取一份包含格式不一致資料的 Excel 檔
2. 對每一列資料，呼叫 LLM API 進行格式標準化
3. 將清理後的資料寫回新的 Excel 檔案
4. 如果某一列資料 AI 無法確定，標記為「需人工審查」
請幫我設計這個程式的架構
設計提醒：無法確定的資料不要讓 AI「猜」，一律標記為需人工審查，避免錯誤資料流入下游報表。
程式碼範例

讀取與篩選試算表（虛擬碼）

載入 pandas 套件

# 讀取 Excel 檔案
資料表 = 讀取Excel("sample_data.xlsx", 工作表="Sheet1")

# 篩選：銷售金額超過 40000
篩選結果 = 資料表[ 資料表["銷售金額"] > 40000 ]

# 排序：由高到低
排序結果 = 篩選結果.依照("銷售金額", 由大到小=真)

# 計算加總
總計 = 篩選結果["銷售金額"].加總()

# 輸出到新 Excel 檔案
排序結果.寫入Excel("filtered_result.xlsx", 不含索引=真)

批次彙整多份活頁簿（虛擬碼）

資料夾路徑 = "報表資料/"

程式碼範例

AI 輔助的格式標準化（虛擬碼）

函式 標準化欄位(原始值, 欄位類型):
    提示詞 = f"""
    我有一筆資料："{原始值}"
    這是「{欄位類型}」欄位的值，請轉換為標準格式：
    - 金額：只回傳數字（不含符號與逗號）
    - 日期：轉換為 YYYY-MM-DD 格式
    - 無法判斷：只回傳「UNKNOWN」
    """
    回傳 呼叫LLM(提示詞)

對 每一列資料 在 資料表 中:
    資料["銷售金額"] = 標準化欄位(資料["銷售金額"], "金額")
    資料["日期"] = 標準化欄位(資料["日期"], "日期")
    如果 任何欄位 == "UNKNOWN":
        資料["備註"] = "需人工審查"
